# Introduction-to-Computer-Vision

### Installs:
pip install numpy opencv-python matplotlib scikit-image scikit-learn pillow


### How to run:
Run from the project root folder:

'python Assignments/<name_of_script>.py'


### Notes:
- Scripts that show plots open plot windows, close a window to let the script continue.
- `KNN.py` opens no windows. It writes its report to `KNN_results.md` (tables and plots in one file). 
- Result images are saved in the folder you run the script from.
- Images are in `Images/` and the CIFAR-10 dataset is in `cifar-10/`, so no extra downloads are needed.
